# صهيل — المنظومة الذكية للرعاية الصحية والتموين الآلي للخيول

منظومة ذكية منخفضة التكلفة مبنية على **ESP32**، تغذّي الخيل آلياً عبر بريمة، وتعبّي الماء بمضخة، وتقيس المستويات بحساسين فوق صوتيين **HC-SR04**، وتعرض كل شيء عبر واجهة ويب على الجوال دون إنترنت. وتوظّف نموذج **Isolation Forest** الذي يتعلّم النمط الطبيعي لكل خيل وينبّه مبكراً عند أي تغيّر.

**الفريق:** ليان خلف الحربي · ربى عبدالله الشهري
**الإشراف:** المهندسة منار الصواط · المهندسة عبير الحليفي
**الجهة:** الكلية التقنية الرقمية للبنات بجدة — هاكاثون رُبّان 2026

## 1) تجربة الواجهة دون الجهاز

1. افتح رابط `demo/`.
2. الدخول: اسم المستخدم `admin` وكلمة المرور `1234`.
3. **لوحة التحكم:** مستوى العلف والماء والعد التنازلي للوجبة، وزر «تقديم وجبة الآن».
4. اضغط بطاقة الخيل **«ريم»** لعرض الملف الصحي والرسم البياني لثلاثين يوماً.
5. في بطاقة **تحليل الذكاء الاصطناعي** اضغط «محاكاة حالة مبكرة» ليظهر «تنبيه مبكر» مع درجة الشذوذ وسببه.
6. من الشريط السفلي: الاستهلاك، التنبيهات، المستخدمون، الإعدادات.

> النسخة التجريبية لا تتصل بأي جهاز؛ القراءات محاكاة وأزرار الحفظ لا تغيّر شيئاً حقيقياً.

## 2) تشغيل الكود على الجهاز

### المكونات

| القطعة | الوظيفة |
|---|---|
| ESP32 DevKit V1 | المتحكم ونقطة الوصول اللاسلكية وخادم الواجهة |
| خزان علف + بريمة + موتور عبر ريليه | صرف الوجبات |
| HC-SR04 ×2 | مستوى العلف في الخزان، ومستوى الماء في الوعاء |
| مضخة ماء + ريليه | تعبئة وعاء الماء |
| بازر | التنبيه الصوتي |
| 4 بطاريات ليثيوم | التغذية الكهربائية |

### التوصيلات (أطراف ESP32)

| الطرف | التوصيل |
|---|---|
| D13 | ريليه البريمة |
| D26 | ريليه المضخة (يعمل عند LOW) |
| D5 / D18 | Trig / Echo لحساس العلف |
| D27 / D33 | Trig / Echo لحساس الماء (الحساس على 3.3V) |
| D14 | البازر |

### الخطوات

1. ثبّت **Arduino IDE** وأضف لوحات ESP32 (Boards Manager ← esp32 by Espressif).
2. افتح `code/arduino/sahil_v3_2/sahil_v3_2.ino`.
3. **غيّر كلمة مرور شبكة الجهاز** في السطر:
   ```cpp
   const char* password = "CHANGE_ME_123";
   ```
   (8 أحرف على الأقل — لا تُنشر كلمة المرور الحقيقية).
4. اختر اللوحة **ESP32 Dev Module** والمنفذ الصحيح، ثم **Upload**.
5. من الجوال اتصل بشبكة الجهاز **Horses restaurant**، وافتح `http://192.168.4.1`.
6. أول دخول: `admin` / `1234`، ثم غيّر كلمة المرور من صفحة الحساب.

### المعايرة

في أعلى الكود:

```cpp
const float W_SENSOR_H = 12.0;  // المسافة من حساس الماء إلى قاع الوعاء الفارغ (سم)
const float W_LOW_CM   = 1.5;   // مستوى تشغيل المضخة
const float W_HIGH_CM  = 4.0;   // مستوى إيقافها
```

قِس المسافة والوعاء فارغ واكتبها في `W_SENSOR_H`.

### الحماية المبرمجة

- إيقاف المضخة إذا كانت قراءة الحساس غير صالحة.
- حد أقصى لتشغيل المضخة دقيقة واحدة، ثم قفلها 5 دقائق.
- الجهاز لا يتعلّم معدل الشرب من الأيام التي صدر فيها تنبيه.

## 3) الذكاء الاصطناعي

- **الخوارزمية:** Isolation Forest من 200 شجرة، مبرمجة من الصفر بلغة JavaScript داخل الواجهة، دون مكتبات خارجية، وتتدرّب في المتصفح في أقل من ثانية.
- **المدخلات اليومية:** نسبة الأكل، نسبة الشرب، تغيّر الشرب عن الأيام الثلاثة السابقة، حرارة الخيل، النبض.
- **المخرجات:** طبيعي / تنبيه مبكر (درجة شذوذ ≥ 56%) / تنبيه (≥ 68%)، مع سبب التنبيه، بشرط أن يكون التغيّر في اتجاه الخطر.
- **يبدأ بعد 7 أيام من البيانات**، وقبلها تعمل قاعدة 70%.
- **على الجهاز:** يتعلّم ESP32 معدل الشرب الطبيعي (متوسط متحرك) وينبّه بالبازر عند انخفاضه بوضوح.

### النتائج (بيانات محاكاة لـ 30 يوماً)

| المؤشر | النتيجة |
|---|---|
| أيام الخلل المكتشفة | 2 من 2 |
| إنذارات خاطئة على الأيام الطبيعية | 0 |
| حالة مبكرة لم تكشفها قاعدة 70% | درجة شذوذ 64% ← تنبيه مبكر |

> النموذج قُيّم على بيانات محاكاة. اختباره على قراءات الجهاز الحقيقية هو المرحلة التالية، بعد جمع 7 أيام على الأقل من بيانات الشرب الفعلية.

## 4) النموذج ثلاثي الأبعاد

صفحة ويب مبنية بلغة JavaScript ومكتبة **Three.js** (تُحمَّل من CDN، فتحتاج إنترنت). تعرض كل قطعة مع شرحها، ومحاكاة لمنطق المضخة، وشاشات واجهة الويب.
